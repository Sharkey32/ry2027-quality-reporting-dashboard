# RY 2027 Pay-for-Reporting Quick Reference

Static single-page reference for Medisolv CSMs covering the three Reporting Year 2027 pay-for-reporting programs: **IQR**, **Promoting Interoperability (PI)**, and **OQR**.

Built from the FY 2027 IPPS/LTCH PPS Final Rule (CMS-1849-F) and the 2027 OPPS Proposed Rule (CMS-1850-P). Internal quick-reference only — not a substitute for the underlying CMS rule text.

## Development

This is a plain static site — no build step. Open `index.html` directly in a browser, or serve it locally:

```bash
npx serve .
```

## Deployment

Deployed on [Vercel](https://vercel.com) as a static site. Pushing to `main` triggers a new deployment automatically once the repo is connected in the Vercel dashboard.
